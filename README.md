## 🚀 Projetos em destaque

### ⚡ Detecção de Fraudes em Tempo Real

🔄 **Status:** Em desenvolvimento  
🤝 🤝 **Colaboração:** Comunidade Fabric Lusófono | [@ShalomAndre](https://github.com/ShalomAndre)

Projeto que estou iniciando em colaboração com a **Comunidade Fabric Lusófono**, com o objetivo de desenvolver uma solução de detecção de fraudes em cartões de crédito utilizando **Microsoft Fabric Real-Time Intelligence**.

A proposta é simular uma operação financeira em tempo real, gerando transações legítimas e fraudulentas e construindo uma arquitetura capaz de analisar esses eventos à medida que acontecem.

**Fluxo proposto da solução:**

1. 🐍 **Gerar:** Notebook Python simula continuamente transações legítimas e fraudulentas.
2. 📡 **Ingerir:** Eventstream recebe os eventos em tempo real.
3. 🗄️ **Armazenar:** Eventhouse mantém os dados para processamento e análise.
4. 🔎 **Detectar:** KQL identifica padrões e comportamentos potencialmente fraudulentos.
5. 🚨 **Alertar:** Activator monitora as condições definidas e dispara alertas para possíveis fraudes.
6. 📊 **Visualizar:** Real-Time Dashboard apresenta as transações, fraudes identificadas e indicadores operacionais.

`Python Notebook` → `Eventstream` → `Eventhouse` → `KQL` → `Activator` → `Real-Time Dashboard`

> 💡 **Objetivo:** demonstrar como uma instituição financeira pode identificar transações potencialmente fraudulentas enquanto elas acontecem, reduzindo o tempo entre a ocorrência e a identificação da possível fraude.
